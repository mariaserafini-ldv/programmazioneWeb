Introduzione a Flask

Fino ad ora ogni pagina era un file HTML sempre uguale. Con Flask puoi creare pagine che cambiano ogni volta che il browser le richiede.

Approfondimento
Gli esempi di questa pagina simulano Flask nel browser, per mostrarti cosa succede passo per passo. Per provarlo davvero, devi eseguire il codice sul computer in locale.

01 · definizioni

Statico o dinamico

Una pagina statica è un file HTML che il server consegna così com'è. Una pagina dinamica viene costruita al momento: lo stesso indirizzo può restituire risposte diverse. Confronta i due casi.

02 · workflow

Come lavorare con Flask

Per passare da una pagina HTML statica a un sito dinamico, prepariamo un piccolo progetto Python. Segui i passaggi nell'ordine: installeremo Flask, organizzeremo i file, scriveremo il codice e infine avvieremo il server per visitare il sito con il browser.

1. Installare la libreria Flask

Flask è una libreria (o meglio un micro framework) di Python: aggiunge al linguaggio gli strumenti necessari per ricevere richieste HTTP dal browser e costruire le risposte. Si installa una sola volta nell'ambiente Python che useremo per il progetto.

terminale
pip install flask

Il comando pip è il programma che installa le librerie Python. A scuola la libreria è già installata.

2. Preparare la struttura delle cartelle

Nella cartella del progetto predisponi app.py e le due cartelle che Flask riconosce automaticamente:

struttura del progetto
mio_progetto/
│
├── app.py
│
├── templates/
│   └── index.html
│
└── static/
    └── style.css
  • templates/ contiene i file HTML che Flask userà come modelli di pagina;
  • static/ contiene i file statici, per esempio fogli CSS, immagini e JavaScript.
I nomi templates e static vanno scritti esattamente così, perché Flask li cerca in queste posizioni per impostazione predefinita.

3. Creare i file del progetto

Il file Python definisce l'applicazione e la pagina da restituire. I file HTML e CSS restano separati: in questo modo possiamo occuparci della logica con Python e della presentazione con HTML e CSS.

templates/index.html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
  <title>Il mio primo sito</title>
</head>
<body>
  <h1>Ciao dal mio sito!</h1>
  <p>La pagina è stata inviata da Flask.</p>
</body>
</html>
static/style.css
body {
  font-family: Arial, sans-serif;
  margin: 40px;
}
h1 {
  color: steelblue;
}
Da ricordare → il codice Python viene eseguito sul server. Il browser riceve la risposta HTML e interpreta HTML e CSS sul client (cioè il dispositivo dell'utente). Il browser non riceve né esegue il codice Python di app.py.

4. Avviare il server Flask

Apri il terminale nella cartella principale del progetto, quella in cui si trova app.py, e lancia:

Il server è un programma in esecuzione sul tuo computer che resta in ascolto delle richieste del browser. Quando riceve una richiesta per un indirizzo gestito dall'applicazione, Flask esegue la funzione associata alla route e invia al browser la risposta prodotta.

127.0.0.1 indica il computer su cui stai lavorando (localhost); 5000 è la porta usata in questo esempio. Finché il server è attivo, il terminale resta occupato: per fermarlo, torna nel terminale e premi CTRL+C.

5. Visualizzare il sito nel browser

Apri il browser e digita l'indirizzo mostrato dal terminale:

03 · routes

Ogni indirizzo ha la sua funzione

Con @app.route si collega un indirizzo (URL) a una funzione Python: la funzione sceglie cosa rispondere. Scrivi un indirizzo nel browser simulato, oppure scegline uno, e osserva quale funzione viene eseguita.

04 · template

Dai dati Python alla pagina HTML

Scrivere l'HTML dentro Python diventa presto scomodo. Con render_template l'HTML sta in un file a parte (il template) e Python gli passa i dati: nel template compaiono come {{ nome }}, e con {% if %} si può scegliere cosa mostrare.

HTML prodotto · quello che vede l'utente

Prova a scrivere <b>ciao</b> come nome: Flask lo mostra come testo, non lo interpreta come HTML. Si chiama autoescape e impedisce a chi compila un modulo di inserire codice nelle tue pagine.

05 · liste e cicli

Una lista Python diventa una lista HTML

Con {% for %} il template ripete un pezzo di HTML per ogni elemento di una lista. È il passaggio chiave per la dinamicità e la gestione di elementi multipli: un elenco diventa un elenco di schede, senza scrivere l'HTML a mano.
