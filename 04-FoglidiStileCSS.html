03 · sintassi

        
Anatomia di una regola CSS

        
Ogni regola ha sempre la stessa forma e contiene i seguenti elementi:

      

      

        

          

            
            
            
            
            
            
          

          

            
style.css

            
h1 {
  color: blue; /* Colore del testo blu */
  text-align: right; /* Testo allineato a destra */
}

          

        

        

          

          
Ricorda → proprietà e valore sono separati da :; ogni
            dichiarazione finisce con ;; il blocco sta tra { }. Dimenticare un ;
            è l'errore più frequente.

        

      

    


    
    

      

        
04 · selettori

        
A chi si applica lo stile?

        
Il selettore sceglie gli elementi a cui applicare lo stile.

      

      

        

          
h1

          
Tipo (tag)

          
Colpisce tutti gli elementi di quel tipo.

          h1 { color: blue; }
        

        

          
.

          
Classe

          
Colpisce più elementi, anche di tipo diverso. Nell'HTML: class="..."

          .evidenziato { ... }
        

        

          
#

          
Id

          
Colpisce un solo elemento: l'id è unico nella pagina (serve anche per i link interni).

          #bottone-invio { ... }
        

      


      

        

          
scegli un selettore

          

          

            
            
          

          
Clicca un selettore per vedere quali elementi
            colpisce.

06 · div e span

        
Integrazione HTML : i tag div e span

        
<div> è un elemento di blocco: occupa tutta la larghezza e
          va a capo. 
<span> è in linea: resta dentro il testo.
          
Da soli non fanno nulla: servono per applicare stili.
        

      

      

        
        

          contenitore
          
        

        

          gli span
          
        

      

      

        

          

            
Menu

            
Contenuto principale

            
Info

          

          
Questo testo contiene uno span e un altro
              span: restano nella stessa riga del paragrafo.

        

        

          

            
CSS applicato

            

          

          
Layout moderno → i div si
            usano al posto delle tabelle per disporre la pagina: con display: flex (o grid) le
            colonne si adattano alla larghezza. Le tabelle restano per i dati tabellari.
